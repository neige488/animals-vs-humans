# 버블건 휴대 자세

허리 고정 위치 때문에 손과 총이 분리된다는 실제 사용자 피드백을 수정한다. 보유 인간 Humanoid 리그의 어깨·팔꿈치·손을 사용하며, Animator가 걷기/대기 자세를 적용한 뒤 두 관절 팔 보정으로 오른손을 손잡이에, 왼손을 앞쪽 받침에 맞춘다. 다리의 기존 이동 애니메이션은 유지한다. 보이는 인간 모델은 조준 방위로 부드럽게 회전하고 판정용 컨트롤러는 기존 이동 회전 규칙을 유지한다.

변신 시 기존 총 오브젝트와 자세 컴포넌트가 함께 제거된다. 원격 인간도 같은 표현 컴포넌트를 사용한다. 버블의 판정 시작점은 몸 기준 높이 1.3m와 조준 오른쪽 0.1m로 맞춘다. 총구까지 앞으로 이동시켜 벽 너머에서 탄이 시작되는 방식을 사용하지 않는다.

실제 구매 리그의 양손 그립 거리 검사에서 기존 상태는 오른손 오차 0.417m로 실패했다. 수정본은 이동하면서 0/65/145/270도 조준을 검사하고 실제 엔진 렌더를 기록한다. 재장전 손동작과 손가락별 정밀 애니메이션은 후속이며 현재 전용 총기 애니메이션 클립은 추가하지 않는다.

총 Transform에서 방향을 역산하지 않고 별도의 조준 방위를 유지한다. 입력 없는 프레임은 마지막 유효 조준을 유지하며, 호스트는 이 방위를 기존 원격 시각 yaw에 보낸다. 원격은 매 상태 수신 때 이 값을 적용하므로 과거 발사의 부모 상대 회전 오프셋이 남지 않는다. 원격 pitch는 현재 버블 방향으로 갱신하는 기존 범위를 유지한다. 발사하지 않는 동안의 원격 상하 조준 전송은 후속이다.
