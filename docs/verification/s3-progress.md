# S3 봇 공방 구현

상태: 로컬 구현·자동 검증 완료, 독립 리뷰와 실제 제품 검증 대기. 기준 S2+S4 f81edc5에 S1/S2/S4 후속 수정을 포함했다. PA-5와 PA-16은 아직 통과하지 않았다.

## 구현 결정

- 봇은 호스트 UnityPlaytestSession에서 IsBot 슬롯만 관찰하고 동일 SubmitInput 경로로 이동·점프·발사·재장전·근접을 요청한다. 명중/변신 결과를 직접 변경하지 않는다.
- S5 소유권 전환은 인계 즉시 기존 입력을 0으로 초기화한다. RemoteWorld는 Step을 실행하지 않으므로 자체 봇 판정을 실행하지 않는다.
- 경로 초안은 실제 지형을 측정한 0.5m 격자 A*이다. 제작 중인 작은 마을의 계단과 지형 변경을 반영하며 외부 NavMesh bake 의존성을 추가하지 않는다. 원본 구매 에셋은 보존하고 생성된 캐릭터 prefab의 vendor NavMeshAgent를 제거하여 위치 쓰기 주체를 CharacterController 하나로 만든다.
- 영구 정지/접근 불가가 테스트에서 나오면 실패로 보고 수정한다. 자동 시뮬레이션은 실제 사람 2~4명의 재미 의견과 양 OS 플레이를 대체하지 않는다.

## 구현 및 검증 결과

- RED 86eb8b7: 실제 Unity에서 12초 동안 6m 이상 움직인 봇 0명으로 실패했다. GREEN 51b910e: 구매 에셋을 적용한 실제 씬에서 쉘터 이동, 버블 발사, 재장전, 물리 근접 변신 공방을 통과했다.
- 초기 GREEN 시도에서 계단 샘플의 과도한 하단 캡슐 검사와 창고 지붕 아래 바닥 누락으로 정체가 발견됐다. 실제 CharacterController가 오를 수 있는 작은 계단은 상체 여유와 이웃 높이 차이로 검사하며, 수직 레이의 여러 바닥 후보 중 몸이 들어갈 수 있는 가장 낮은 바닥을 선택하도록 수정했다. 통과 기준을 낮추지 않았다.
- 인간 봇은 슬롯별로 쉘터를 분산 선택하고, 4m 안의 동물 위험에서는 다른 쉘터로 이동한다(재선택 간격5초). 동물 봇은 가까운 인간을 추격한다. 공격은 실제 시야·사거리 안에서 동일 Attack 입력으로 요청하고, 탄창이 비면 Reload 입력을 보낸다.
- 경로는 약0.8초마다 다시 계산한다. 2초 이상 이동 정체에서는 지형을 다시 읽어 새 장애물을 반영한다. 인접 캐릭터 회피와 정체 시 측면 이동·점프도 동일 입력을 사용한다. 조준/위험/회피 초기값은 출시 밸런스가 아니다.
- 실제 동적 진입로 봉쇄 테스트: 이동 시작1.5초 후 구석 쉘터 앞에 벽을 추가하고, 준비 시간이 끝나기 전에 옥상·구석·창고 각각2명 이상이 접근하는 것을 관찰했다. 실패한 경로를 순간이동으로 보정하지 않았다.
- 실제 위협 후 도주 테스트: 같은 추격 라운드 안에서 4m 이내 동물에 위협받은 인간 봇이 변신 전에6m 이상 이동한 것을 확인했다. 다음 라운드 위치 초기화는 도주로 세지 않는다.
- Unity6000.6.3f1 macOS batchmode: 전체 PlayMode13/13PASS(`/private/tmp/avh-s3-full.xml`, `.log`), 강화한 BotTests2/2PASS(`/private/tmp/avh-s3-bots.xml`, `.log`). 별도 순수Core13/13PASS 및 Unity 어셈블리Runtime컴파일PASS. 기존 S1/S2/S4 물리 fixture는 봇 자동 입력을 끄고, BotTests는 켠 채 검증한다.
- 구매 파생 Human/Fox prefab의 NavMeshAgent 제거를 실제 Configure 실행과 생성 파일에서 확인했다. 원본 `.unitypackage`와 ThirdParty 구매 파일은 Git ignored로 유지한다. Library/Builds를 다른 checkout에서 복제하지 않았다.

## 통합 및 미검증 경계

- S5는 호스트에서만 Step을 실행하며, IsBot이 꺼진 슬롯은 BotDirector가 조작하지 않는다. S5가 조작권 인계 시 기존 입력을 즉시 지우므로 봇 입력이 사람에게 남지 않는다. 이 결합의 실제 연결 회귀는 통합 단계에서 검증한다.
- S1/S2 후속 af081d0→f6bc2ed, ec6ce74→5182b55. S4 Discovery 수정96215a4→4e4107c,0436ece→8c84e83. GamePresentation 충돌에서는 S2 BirthSecondsRemaining 타이머와 S1 결과 패널을 유지했다.
- 실제 사람2~4명과 양 OS 연속 플레이, 사람 시점에서의 공방 영상, 인간 방어·동물 추격·변신 후 지속 의향 의견은 아직 없다. PA-16은 사람 참여 대기 BLOCKED이며 자동 시뮬레이션으로 재미를 추정하지 않는다. Windows 검증은 사용자가 요청한 순서대로 구현 이후 수행한다.
