# 상단 초상화 HUD

## 확정한 배치

상단 중앙에 참가자 12명의 실제 캐릭터 초상화를 표시한다. 인간은 왼쪽, 동물은 오른쪽으로 모으며 양 끝에는 인원 숫자만 표시한다. 인간과 동물의 경계에 있는 VS는 인원 변화에 따라 줄다리기처럼 이동한다. 각 얼굴은 참가자 슬롯의 정체성을 유지한다. 각 진영 안에서는 슬롯 순서를 유지해 불필요한 이동을 줄인다.

12개 얼굴을 위한 폭과 VS를 위한 좁은 여백의 전체 폭은 일정하다. 변신 때 해당 얼굴의 이미지가 바뀌고, VS와 주변 얼굴은 0.3초 동안 감속하며 새 위치로 이동한다. 새 동물 얼굴만 작게 올라왔다가 정렬된다. 연속 변신은 현재 보이는 위치에서 새 목표로 이어지고, 라운드 재시작은 준비 상태에 즉시 정렬한다.

## 표현

- 1280×720 기준 상단 패널 708×64, 초상화 테두리 42×46, 46 간격.
- 어두운 작은 배경 위에 밝은 숫자·VS. 인간은 하늘색, 동물은 주황색 테두리로 구분한다.
- 내 캐릭터 아래에는 짧은 흰색 표시를 둔다.
- 남은 시간은 바로 아래 작은 별도 배경에 표시한다.
- 동물 탄생 안내도 같은 Canvas 안으로 옮겨 모든 해상도에서 타이머 아래에 배치한다. 전용 깊이 초기화 UI 카메라를 사용해 가까운 벽이나 캐릭터가 HUD를 가리지 않게 한다.
- 현재 범위는 상단 HUD이며 로비·하단 무기·Esc 메뉴·결과 창의 전체 재설계는 포함하지 않는다.

## 초상화와 성능

Polyperfect 보유 모델의 머리를 오프라인으로 렌더링한 160×160 PNG를 사용한다. 인간 6종과 동물 6종을 카탈로그에 연결한다. 구매 에셋 및 파생 PNG는 Assets/ThirdParty 아래에 두어 Git에서 제외하며 게임 빌드에는 포함한다. 보유 에셋 구성 명령은 초상화도 함께 생성한다.

경기 중 얼굴용 카메라나 복제 리그를 실행하지 않는다. 실제 행동을 복사하는 얼굴 표현은 사용자가 별도 옵션으로 성능 비교 후 검토하기로 했다. 향후 도입한다면 얼굴 방향 제한, 낮은 해상도와 갱신 빈도, 그림자/배경 제외를 우선 검토한다. 현재 UI 애니메이션은 위치·크기·이미지 알파만 바꾼다.

## 검증 경계

실제 세션 생성·라운드 진행·공개 변신 판정·퇴장으로 HUD의 참가자 수, 얼굴 종류, VS 이동·재시작·연속 변신을 검증한다. 1280×720 및 1920×1080에서 실제 Unity Canvas를 렌더링한다. 영상은 검수용 설정(첫 동물 3마리)을 사용하며 제품 기본 동물 수 설정을 변경한 것이 아니다.
