# 실시간 플레이 디버그 설정

오른쪽 게임 화면 오버레이를 F1 또는 디버그 버튼으로 열고 접는다. Esc로도 접는다. 패널은 봇/라운드를 멈추지 않는다. 열린 동안 마우스는 패널 조작에 사용하여 시점 회전과 공격은 막고 WASD 이동은 유지한다. 호스트만 변경하며 참가자 패널은 읽기 전용이다.

라운드·이동·버블건 탭의 슬라이더와 ± 버튼, 충돌/아군 밀치기 토글은 변경 즉시 현재 세션에 적용한다. 기존 예약 적용 API는 호환용으로 유지하되 기본 UI는 예약 버튼을 쓰지 않는다.

- 시간은 이미 경과한 시간을 유지한다. 드래그 중에도 실시간 적용한다. 더 짧게 설정해 현재 단계 시간이 끝났으면 다음 월드 틱에서 다음 단계로 넘어간다. 다음 틱 전에 다시 늘리면 원래 경과 시간을 유지한다.
- 최초 동물 수와 공격 유예는 다음 탄생부터 사용한다. 이미 변신한 동물을 되돌리거나 추가 변신을 강제하지 않는다.
- 새 버블은 현재 설정을 사용한다. 비행 중 버블은 발사 당시 속성을 유지한다.
- 탄창 감소는 남은 탄약을 상한으로 제한하고 증가 자체로 재충전하지 않는다. 진행 중 재장전과 인간 발사 간격은 지난 시간을 유지하여 새 지속 시간으로 조정한다.
- 실시간 변경은 메모리에 적용한다. 현재 설정 저장은 XML에 저장하며 저장 실패 시 이번 실행 값은 유지하고 기존 오류/재시도 흐름을 사용한다.

1280×720 창 기준 패널은 폭344, 오른쪽8 여백, 상단HUD 아래에 배치하고 내부 항목만 스크롤한다. 1920×1080에서도 오른쪽에 붙는다. 패널 기본은 접힘이다.
