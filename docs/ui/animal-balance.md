# 종별 동물 밸런스 · 실시간 테스트

공통 동물 이동 속도·점프 높이에 종별 배율을 곱한다. 버블 충격은 피격 시점의 대상 종 배율로 수평 및 위로 밀리는 초기 속도를 조절한다. 실제 이동 거리는 감속·충돌·지형에 따라 달라진다. 인간과 알 수 없는 동물 ID는 배율1이다.

| 종 | 속도 | 점프 높이 | 밀림 |
|---|---:|---:|---:|
| 여우 |1.10|1.10|1.15|
| 늑대 |1.15|1.00|1.00|
| 불곰 |0.80|0.65|0.45|
| 멧돼지 |1.05|0.70|0.65|
| 토끼 |1.05|1.55|1.40|
| 펭귄 |0.90|0.90|0.80|

오른쪽 디버그의 동물 탭에서 종을 고른다. 속도·점프 배율0.05~3, 밀림0~3을 슬라이더와 ± 버튼으로 조절한다. 속도는 즉시, 점프는 다음 점프, 밀림은 다음 피격부터 적용한다. 이미 진행 중인 점프나 충격은 소급 변경하지 않는다. 이 동물만 기본값과 전체 기본값을 구분하며 현재 설정 저장으로 재실행에 유지한다. XML에서 새 필드가 없는 이전 설정은 해당 종의 신규 기본값을 유지한다.

호스트만 변경하며 현재 설정의 종별 데이터도 네트워크로 전달된다. 관성 설정 추가로 스키마가 바뀌어 avh-private-7을 사용하고 구 버전은 연결 전에 거부한다. 봇과 사람의 몸체가 같은 규칙을 사용한다. AI의 판단·반응 속도 개선은 별도 범위다.

## 종별 움직임 성격 (game-feel S1)

속도·점프·밀림 배율은 위 합의값 그대로 두고, 종별 성격은 **가속·감속 곡선 배율**과 동작 표현으로 만든다. 곡선 배율은 공통 관성 시간(기본 0.12초)에 곱하므로 관성 0이면 모든 종이 기존처럼 즉시 움직인다. 최대 0.23초로 8~12세 조작 반응성을 우선했다.

| 종 | 출발×(초) | 정지×(초) | 동작 표현 |
|---|---:|---:|---|
| 인간 | 1.0 (0.12) | 1.0 (0.12) | 조준 중 옆걸음은 다리 ±75°·상체 조준 유지, 뒷걸음은 보폭 역재생 |
| 여우 | 0.8 (0.10) | 0.9 (0.11) | 날렵한 전경·회전 기울기 |
| 늑대 | 1.0 (0.12) | 1.0 (0.12) | 꾸준한 전경 |
| 불곰 | 1.7 (0.20) | 1.6 (0.19) | 작은 기울기·큰 착지 눌림·반동 없음(묵직) |
| 멧돼지 | 1.2 (0.14) | 1.8 (0.22) | 가장 큰 돌진 전경, 멈출 때 밀림 |
| 토끼 | 0.6 (0.07) | 0.7 (0.08) | 착지 후 튕기는 반동 스프링, 전용 Jump_Up 클립 |
| 펭귄 | 1.1 (0.13) | 1.9 (0.23) | 좌우 뒤뚱, 미끄러지듯 정지 |

애니메이션은 `CharacterAnimator`가 공개 운동 상태(`LocomotionState`) 하나로 재생한다. 구매 컨트롤러 원본은 수정하지 않고 런타임 Playables 그래프가 각 컨트롤러의 대기·걷기·달리기(·토끼 점프) 클립을 섞는다. 걷기↔달리기는 한 보폭 위상으로 동기화하고 지면 속도에 맞춰 재생 속도를 조절하며, 정지 0.1초 유지·공중 0.08초 유예로 깜빡임을 막는다. 원격 화면은 S4 전까지 보간 이동에서 추정한 상태로 같은 경로를 쓴다.
