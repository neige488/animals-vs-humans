# 그래픽 품질 · 화면 흔들림 (참가자 로컬 설정)

호스트 테스트 설정(`playtest-settings.xml`)과 별도로 각 PC의 `display-settings.xml`에 저장한다. 호스트와 일반 참가자 모두 바꿀 수 있다.

```text
시작 화면 (기존 화면 아래)
그래픽 품질  [낮음] [보통] [■높음]
화면 흔들림  [■켜기] [끄기]

Esc 메뉴 (매치는 계속 진행)
[테스트 설정 열기] ←호스트만
[계속하기]
그래픽 품질 [낮음][보통][■높음]
화면 흔들림 [■켜기][끄기]
                    [방 나가기]
```

- 선택 즉시 적용 → 이 PC에 저장 → 다음 실행에도 유지. 최초 실행은 높음·켜기.
- 저장 실패 시 "이번 실행에만 적용됩니다"를 4초 보이고 플레이는 막지 않는다. 다음 저장이 성공하면 현재 선택 전체를 저장한다. 손상되거나 알 수 없는 값은 최초 실행 기본값으로 읽는다.
- 시작 화면은 1280×720에서 아래 행이 들어가도록 전체를 80px 올렸다.

| 품질 | 그림자 | 효과 입자 | 흔들림 크기 |
|---|---|---|---|
| 높음 | 부드러운 그림자 110m, 해상도 높음, AA 4 | 100% | 100% |
| 보통 | 딱딱한 그림자 70m, 해상도 보통, AA 2 | 70% | 85% |
| 낮음 | 그림자 끔, AA 0 | 40% (최소 1개·고리 유지) | 70% |

포스트프로세싱·식생 흔들림은 game-feel S5가 같은 단계에 추가한다. 흔들림 끄기는 품질과 별개로 언제나 흔들림을 없앤다.

개발 빌드 `-avhMenuPreview <폴더>`는 격리 프로필로 시작 화면·Esc 메뉴·저장 실패 안내·타격 탭을 캡처하고 종료한다.
