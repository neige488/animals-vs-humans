# 인간 6종 · 동물 6종

Polyperfect 보유 에셋으로 인간 6종(산책객, 여행객, 소방관, 경찰관, 건설 작업자, 탐험가)과 동물 6종(여우, 늑대, 불곰, 멧돼지, 토끼, 펭귄)을 사용한다. 모든 캐릭터는 현재 일반 등급이며 진영별 동일 이동·공격 성능을 사용한다. 개별 능력·뽑기·선택 UI는 이번 범위가 아니다.

인간은 12개 슬롯에 6종이 두 번씩 배정된다. 동물은 호스트가 최초 탄생 및 후속 변신 순서로 6종을 순환 배정한다. 다음 라운드에는 최초 탄생의 시작 종류가 옮겨지고, 인간 외형은 원래 슬롯 기준으로 복구된다. 난입·재접속은 해당 슬롯의 현재 캐릭터를 그대로 이어받는다.

캐릭터 ID·이름·등급을 호스트 상태에 포함하고 클라이언트는 ID로 동일한 프리팹을 찾는다. 탄생 알림은 실제 바뀐 동물의 이름과 등급으로 묶으며 한 번에 여러 종류가 표시되도록 줄바꿈한다. wire schema 변경으로 private protocol은 avh-private-5다. 방 참가자는 같은 빌드를 사용해야 한다.

`import-owned-assets.py`는 두 Polyperfect 패키지를 받으면 12종의 의존성을 기본으로 가져온다. `ConfigureOwnedAssets.Configure`는 ignored ThirdParty 안에 프리팹과 카탈로그를 생성한다. 구매 원본은 Git에 올리지 않는다. 인간은 1.8m로 정규화하고 데모 crouch override를 제거하며, 동물은 원본 rig의 metre scale을 유지하되 토끼는 식별을 위해 0.65m로 보정한다. 데모 AnimationEvent는 게임 로직과 분리하기 위해 실행하지 않는다. 충돌·근접 거리·카메라는 기존 공통 규칙을 유지하므로 동물 크기별 성능 조정은 후속 플레이로 판단한다.

검증은 공개 세션에서 12슬롯·6종 순환·탄생 알림·라운드 초기화와 실제 소켓 캐릭터 전달을 확인하고, Unity에서는 12종 메시·접지·인간 총 자세·원격 외형 교체를 확인한다. 엔진 렌더는 실제 사람 플레이를 대신하지 않는다. Windows와 다인 재미 검증은 사용자 요청으로 유예한다.
