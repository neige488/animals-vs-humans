# 시장 마을과 버블 표현 개선

## 요청과 제작 기준

사용자는 기존 버블의 부자연스러움, 부족한 효과, 좁고 단순한 맵을 지적했고 primitive 효과와 실제 제품 수준의 레벨 디자인을 요청했다. 이번 변경은 기존 12인 추격 규칙을 유지하면서 실제 플레이 가능한 아트·레벨 개선본을 만드는 범위다. 출시 품질 확정은 실제 사용자 플레이와 성능 검수 후 판단한다.

## 레벨 구성

- 플레이 바닥은 46m 정사각형에서 88m 정사각형으로 확장한다(면적 약 3.66배).
- 시장 광장과 폭 6~8m 도로, 남북 순환로, 서쪽 골목과 동쪽 물류 통로를 연결한다.
- 옥상 감시소 `(-20,4,21)`: 계단 진입, 좁은 옥상 방어 공간, 양 측면 낙하 탈출.
- 안뜰 `(25,0,22)`: 후방과 동쪽 담장, 전면과 서쪽 진입. 정면이 막혀도 서쪽으로 우회.
- 작업장 `(22,0,-23)`: 후면·측면 벽, 지붕과 목재 기둥, 열린 두 방향.
- 집은 거리 전면을 형성하고 노점·우물·수레·물자는 사용 목적에 맞춰 배치한다. 보유 Synty 바위·식생·등불·항아리를 사용한다.
- 시각 장식은 길을 막지 않으며, 실제 큰 장애물과 보행면에는 충돌을 둔다. 구입한 원본과 파생 메시·프리팹은 Git 제외를 유지한다.

## 버블과 피드백

- Resources에 포함한 얇은 막 셰이더: 투명한 중심, Fresnel 가장자리, 각도별 무지갯빛, 반사광. 화면 전체 굴절 복사는 사용하지 않는다.
- 성공한 발사에만 공기 방울, 실제 충돌에 물방울·잔물결, 승인된 점프와 착지에 먼지, 실제 진영 변경에 변신 효과를 발생시킨다.
- primitive 효과는 최대 256개로 제한하고 재사용한다. 콜라이더를 비활성화해 게임 판정에 영향을 주지 않는다.
- 발사·파열 음향은 직접 합성하며 거리 감쇠와 짧은 재생 간격 제한을 둔다.
- 원격 버블·파열·변신에도 같은 표현을 적용한다. 재접속 첫 시각 상태에서는 과거 발사·명중을 재생하지 않는다. 원격 점프·착지 효과는 이 버전에서 별도 전송하지 않는다.

## 검증 계약

안뜰은 기존 구석 쉘터 B, 작업장은 기존 창고 쉘터 C의 구체적인 미술·구조 표현이다. `import-owned-assets.py`에 Adventure 패키지를 전달하면 이 생성기에 필요한 바위 03/07·수풀 02·잔디 01·항아리 01·등불 01을 기본으로 포함하며 누락 시 오류를 낸다. 별도 `--extra-prefab` 인자는 필요하지 않다. 구매 에셋이 준비된 현재 PlayMode 검사는 `PrototypeVillage.Build`의 catalog 분기로 실제 `catalog.Village`를 인스턴스화한다. 블록아웃 전용 검사가 아니다.

발사·파열 소리는 batchmode에서 재생하지 않으므로 소리의 체감 품질은 수동 검수 대상이다. 그림자·4x MSAA와 조명 설정은 이번 아트 검수본의 의도한 기본값이며 기기별 품질 선택지는 후속이다.

실제 세션 공개 입력으로 버블 판정·회전·이동·옥상 접근·맵 밖 복귀·봇 우회·상태 인계를 검사한다. 지형 명중 검사는 구체적인 시험 벽을 사용해 특정 옛 맵 건물 위치에 의존하지 않는다. 설정 다음 라운드 적용 검사는 큰 단일 물리 스텝 대신 실제 작은 스텝으로 진행한다.

`TownPresentationTests`는 12명 세션에서 실제 이동·점프·발사 입력을 실행하고 효과 수와 시뮬레이션 CPU 시간을 관찰한다. `-avhCapture`로 실행하면 실제 Unity 카메라 렌더를 PNG 시퀀스로 저장한다. 이 영상은 엔진 내 자동 입력 검사이며 독립 앱에서 사람이 수행한 전체 제품 검증과 구분한다.

넓어진 격자에서 낮은 계단 아래의 바닥을 지지면으로 고르는 문제가 재현돼, 발 중심 바로 위에 다른 지형이 있는지를 좁은 탐침으로 확인하도록 수정했다. 넓은 탐침은 인접 계단을 오인했으므로 사용하지 않는다. 이 수정 후 봇 7개 회귀가 통과했다.

검토 변경은 런타임·셰이더·에디터 생성기·관련 테스트에 걸쳐 15개 파일을 넘지만, 수백 줄의 단일 플레이 화면 개선이며 다수는 Unity 메타데이터·내장 모듈/직렬화 갱신이다. 별도 브랜치에서 이전 검수본을 보존하고 하나의 통합 플레이 증거로 검토한다.
