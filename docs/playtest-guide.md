# Animals vs Humans 플레이 테스트

현재 버전은 3인칭으로 인간과 동물이 쫓고 쫓기는 12명 매치를 시험하는 개발 빌드입니다. 혼자 시작하면 나머지 11명을 봇이 채웁니다.

## 시작하기

macOS는 `AnimalsVsHumans.app`을 실행합니다. Windows는 배포 압축 파일을 폴더 전체로 풀고 `AnimalsVsHumans.exe`를 실행합니다. 실행 파일 옆의 데이터 폴더와 DLL도 함께 있어야 합니다. Windows PC에서의 실제 실행 확인은 후속 검증으로 남아 있습니다.

1. 닉네임을 입력합니다.
2. 혼자 해보려면 **비공개 방 만들기 · 11봇**을 누릅니다. 별도 참가자가 없어도 봇과 바로 플레이할 수 있습니다. 이 PC에서만 시험할 때는 호스트 IPv4 주소에 `127.0.0.1`을 사용할 수 있습니다.
3. 함께 하려면 같은 LAN이나 이미 연결된 VPN에서 호스트의 접근 가능한 IPv4 주소를 입력해 방을 만듭니다. 호스트가 **방 코드 복사**로 전달한 코드를 참가자가 시작 화면에 붙여 넣고 **코드로 참가**를 누릅니다. 방 코드는 네트워크 연결 자체를 만들어 주지는 않습니다.

방을 만든 PC가 호스트입니다. 호스트가 게임 판정과 봇을 실행하므로 플레이하는 동안 켜 두어야 합니다. 현재 연결은 비공개 LAN·기존 VPN 방식이며 Steam 매칭·릴레이는 포함하지 않습니다.

## 조작

| 입력 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 이동 | 3인칭 시점·조준 방향 |
| Space | 점프 |
| 마우스 좌클릭 | 인간: 버블 발사 / 동물: 근접 공격 |
| R | 인간 버블건 재장전 |
| Esc | 메뉴 열기·닫기 |

인간은 버블로 상대를 뒤로 밀며 도망가거나 작은 쉘터에서 함께 방어합니다. 버블은 피해를 주지 않으며 탄창을 소모합니다. 예비탄은 무제한이지만 재장전 시간이 필요합니다. 동물은 가까이 다가가 공격을 한 번 명중시키면 인간을 즉시 동물로 변신시킵니다. 몸이 닿기만 해서는 변신하지 않습니다. 변신한 뒤에도 같은 조작으로 계속 플레이합니다.

## 라운드와 설정

기본 설정은 **준비 20초 → 무작위 동물 2명 탄생 → 추격 3분**입니다. 상단에서 인원·남은 시간·탄생한 동물 종류와 등급을, 하단에서 내 진영·탄창·재장전 상태를 확인합니다. 제한 시간이 끝날 때 인간이 남아 있으면 인간 팀 승리, 그전에 모두 동물이 되면 동물 팀 승리입니다. 마지막 변신과 시간 종료가 정확히 겹치면 인간 팀이 이깁니다. 결과 화면 뒤 다음 라운드가 자동 시작됩니다.

최초 동물은 기본 2초, 도중에 변신한 동물은 기본 1초 동안 공격을 기다리며 이동은 할 수 있습니다. 낙하 피해는 없고 맵 밖으로 떨어지면 진영을 유지해 지상으로 돌아옵니다.

호스트는 Esc 메뉴에서 시간·이동·점프·버블 수치와 몸 충돌·아군 밀치기 옵션을 조정합니다. **다음 라운드에 적용**을 누르면 다음 라운드부터 바뀝니다. 메뉴를 열어도 매치는 계속됩니다. 저장한 설정이 있으면 위 기본값과 다를 수 있습니다.

참가자는 인간 봇을 우선 이어받고, 인간 봇이 없으면 동물 봇을 이어받습니다. 참가자가 나가면 같은 슬롯을 봇이 계속 조종합니다. 호스트가 방을 나가거나 연결이 종료되면 참가자의 매치도 승패 없이 중단되며 호스트 자동 교체는 없습니다. Esc 메뉴의 **방 나가기**로 시작 화면으로 돌아갈 수 있습니다.

이번 테스트에는 기본 인간·동물과 버블건, 봇, 비공개 방을 포함합니다. 캐릭터별 특수능력·캐릭터 뽑기는 아직 포함하지 않습니다.
